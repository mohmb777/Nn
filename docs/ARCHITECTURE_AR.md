# البنية التقنية العربية

## تدفق البيانات
1. يعرض WebView موقع Pocket Option.
2. لا تُقرأ بيانات الشموع إلا من واجهة موثوقة ومتحقق منها.
3. تمر الشموع عبر التحقق من سلامة البيانات ثم تُخزن محلياً.
4. تستقبل StrategyEngine الشموع المكتملة فقط.
5. ينتج المحرك إشارة قابلة للتتبع أو WAIT.
6. يمر أي أمر مستقبلي عبر إدارة المخاطر ثم التحقق من التنفيذ.
7. لا يوجد في النسخة الحالية اتصال تنفيذ حقيقي؛ جميع وظائف التداول قيد التطوير.

## حدود مهمة
- WebView لا يضمن بقاء الصفحة عاملة بعد قتل عملية التطبيق.
- لا يجوز تخمين بيانات Canvas أو استخراج قيم سعرية من البكسلات ثم وصفها بأنها بيانات دقيقة.
- Pine Script المغلق أو الصور لا تكشف بالضرورة كامل منطق المؤشر.
- نتائج الاختبار التاريخي تقريبية ولا تشمل كل ظروف التنفيذ الفعلية.
- لا تحفظ مفاتيح API في Git أو ملفات الإعدادات المضمنة بالتطبيق.

## الحالة الحالية
الواجهة العربية والمتصفح المبدئي وخدمة Foreground Service ونماذج البيانات ومحرك MACD ومستويات القمم/القيعان والاختبار التاريخي المبسط موجودة. الربط الفعلي بمصدر الشموع وOpenRouter وتنفيذ الصفقات غير موجود بعد.
