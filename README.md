# ASTRA AUTO TRADER V2

متصفح تداول هجين لنظام Android، بواجهة عربية كاملة واتجاه RTL، يضم متصفح Pocket Option ومحرك تداول مستقل ولوحة مراقبة.

> **تنبيه التطوير:** هذا المستودع يبدأ من هيكل فارغ. الإصدار الأول يوفّر أساس التطبيق وواجهة عربية ووضعاً تجريبياً آمناً. لا يُفعّل التداول الحقيقي قبل التحقق الفعلي من مصدر بيانات الشموع وآلية تفاعل المنصة، واختبار التنفيذ ومنع التكرار.

## الرؤية

- متصفح مدمج لفتح Pocket Option.
- محرك تداول منفصل عن واجهة لوحة التحكم.
- استراتيجيتا MACD والدعم والمقاومة.
- استيراد Pine Script وتحليل قواعده عبر OpenRouter.
- مختبر اختبار تاريخي ومراقبة الصفقات.
- إدارة المخاطر والتحقق من تنفيذ الأوامر.
- خدمة Android أمامية للإشعار والاستمرارية ضمن قيود النظام.

## التقنية

- Kotlin وAndroid Gradle Plugin.
- Android WebView.
- Jetpack Compose وMaterial 3.
- خدمة Android أمامية.
- Room لتخزين سجل الصفقات والاستراتيجيات.
- واجهة عربية RTL.
- استهداف Android 13 مع دعم armeabi-v7a وarm64-v8a.

## حالة التنفيذ

| الوحدة | الحالة |
|---|---|
| الهيكل الأساسي للتطبيق | قيد البناء |
| واجهة عربية RTL | قيد البناء |
| المتصفح المدمج | هيكل أولي |
| محرك الاستراتيجيات | واجهات أولية |
| OpenRouter | غير موصول بعد |
| استخراج شموع Pocket Option | يحتاج فحصاً تقنياً داخل جلسة فعلية |
| التنفيذ الحقيقي | معطّل افتراضياً |
| الاختبار التجريبي | الأساس المطلوب قبل أي تداول حقيقي |

## البناء

افتح مجلد المشروع في Android Studio ثم نفّذ الأمر: ./gradlew assembleDebug

## الأمان

- لا تضع مفاتيح API داخل المستودع.
- لا ترسل بيانات جلسة Pocket Option إلى خدمات خارجية.
- لا يُسمح بتنفيذ صفقة عند غياب بيانات موثوقة أو عند عدم التأكد من حالة التنفيذ.
- وضع العرض التجريبي لا يرسل أوامر تداول حقيقية.

## ملاحظة مهمة

تشغيل خدمة في الخلفية لا يضمن بقاء WebView أو جلسة الموقع بعد إغلاق العملية أو فرض إيقاف التطبيق. يجب اختبار هذا السلوك على الجهاز المستهدف، ولا يمكن ضمان العمل بعد Force Stop أو إعادة تشغيل الجهاز دون استعادة جلسة آمنة.
