# ASTRA AUTO TRADER V2

متصفح تداول هجين لنظام Android، بواجهة عربية كاملة واتجاه RTL، يضم متصفح Pocket Option ومحرك تداول مستقل ولوحة مراقبة.

> **تنبيه التطوير:** التطبيق يحتوي على واجهة Android عربية ومحرك محاكاة محلي ومحوّل Pine Script محدود. لا يوجد قارئ شموع موثوق أو منفذ Demo/حقيقي موصول بـ Pocket Option؛ لذلك لا يرسل التطبيق أوامر للمنصة.

## الرؤية

- متصفح مدمج لفتح Pocket Option.
- محرك تداول منفصل عن واجهة لوحة التحكم.
- استراتيجيتا MACD والدعم والمقاومة.
- محوّل Pine Script آمن محدود، منفصل عن مصدر البيانات والتنفيذ.
- مختبر اختبار تاريخي ومراقبة الصفقات.
- إدارة المخاطر والتحقق من تنفيذ الأوامر.
- خدمة Android أمامية للإشعار والاستمرارية ضمن قيود النظام.

## التقنية

- Kotlin وAndroid Gradle Plugin.
- Android WebView.
- Jetpack Compose وMaterial 3.
- خدمة Android أمامية.
- Room لتخزين سجل الصفقات والاستراتيجيات.
- واجهة عربية RTL.
- استهداف Android 13 مع دعم armeabi-v7a وarm64-v8a.

## البناء

افتح مجلد المشروع في Android Studio ثم نفّذ الأمر: ./gradlew assembleDebug

## الأمان

- لا تضع مفاتيح API داخل المستودع.
- لا ترسل بيانات جلسة Pocket Option إلى خدمات خارجية.
- لا يُسمح بتنفيذ صفقة عند غياب بيانات موثوقة أو عند عدم التأكد من حالة التنفيذ.
- وضع العرض التجريبي لا يرسل أوامر تداول حقيقية.

## ملاحظة مهمة

تشغيل خدمة في الخلفية لا يضمن بقاء WebView أو جلسة الموقع بعد إغلاق العملية أو فرض إيقاف التطبيق. يجب اختبار هذا السلوك على الجهاز المستهدف، ولا يمكن ضمان العمل بعد Force Stop أو إعادة تشغيل الجهاز دون استعادة جلسة آمنة.


## تكامل Pocket Option — الحالة الحالية

- يفتح المتصفح المدمج العنوان المعتاد: https://pocketoption.com
- يجب على المستخدم اختيار حساب Demo يدوياً داخل المنصة.
- التطبيق لا يستنتج نوع الحساب تلقائياً ولا يعتبر تأكيد المستخدم دليلاً تقنياً على ذلك.
- لا توجد حالياً قراءة موثقة للشموع أو وصلة WebSocket أو واجهة أوامر تجريبية معتمدة.
- لذلك لا يرسل هذا الإصدار أوامر CALL/PUT إلى الموقع. محرك Paper Trading منفصل ومحلي، ولا يمثل صفقات فعلية على المنصة.
- لا يُسمح بإضافة تنفيذ آلي إلا بعد إثبات وضع Demo بطريقة موثوقة، والتحقق من واجهة المنصة الفعلية، واختبار منع تكرار الأوامر والإيقاف الفوري.


## محاكاة strategy.exit على OHLC محلي

أضيفت محاكاة تاريخية محدودة لاستراتيجية Pine واحدة ذات شرط دخول واحد وقاعدة strategy.exit واحدة. تقبل مستويات stop/limit المطلقة، أو loss/profit بوحدات ticks عند إدخال tick size موثوق.

- تُسجّل إشارة الدخول عند إغلاق الشمعة، ويُفترض تعبئة أمر السوق عند افتتاح الشمعة التالية.
- مستويات الخروج التي تُقيّم عند إغلاق الشمعة تصبح فعالة في الشمعة التالية.
- إذا لمس stop وlimit داخل الشمعة نفسها، يختار المحاكي stop أولاً كافتراض محافظ، ويعلّم الشمعة بأنها ملتبسة.
- عند وجود فجوة تتجاوز مستوى الخروج، يستخدم سعر افتتاح الشمعة بدلاً من سعر أفضل افتراضي.
- تُرفض الكميات، وتعدد أوامر الدخول/الخروج، وfrom_entry غير المطابق، والدخول غير المشروط.
- لا تُحتسب العمولة أو الانزلاق أو الرافعة أو حجم المركز، ولا يُغلق المركز المفتوح عند نهاية ملف CSV تلقائياً.
- هذه محاكاة محلية تقريبية وليست نسخة من محاكي TradingView؛ لا تثبت تطابقاً عاماً مع Pine Script.
- لا تتصل هذه الميزة بـ Pocket Option ولا تجلب أسعاراً خارجية ولا تفتح صفقات Paper أو صفقات منصة.

يتطلب loss/profit قيمة tick size من مواصفات الأداة؛ إذا لم تتوفر قيمة موثوقة، يجب عدم تشغيل هذه المحاكاة.
